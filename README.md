# CS210_Project_Three

# Summarize the project and what problem it was solving. 

The problem needing solved in this project was to streamline the process of keeping track of what produce items were purchased on a given day and how many times these items were purchased. To summarize, we had a .txt document that had a list of all the produce items purchased during business hours in the order they were purchased, the goal was to create a program that would tally this information for further study to help the business with produce placement to get sales up of the less popular items.

# Where could you enhance your code? How would these improvements make your code more efficient, secure, and so on? 

I think the main thing I could have done that I didn't think about until after submitting my assignment was the fact that I should have just made a menu function instead of putting the whole menu loop in the main() function. This would declutter the main() function and make the code easier to maintain in the long run if we wanted to add more features.
